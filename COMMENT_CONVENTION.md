# 📘 현업 표준 프론트엔드 주석 컨벤션 및 템플릿 (Enterprise Comment Standard)

> **목적**: 프론트엔드에 익숙하지 않은 백엔드 개발자나 신규 합류자가 코드를 열었을 때 **단 5초 만에 파일의 역할, 백엔드 매핑, 데이터 흐름을 파악**하고 즉시 수정할 수 있도록 설계된 실무 표준 주석 템플릿입니다.

---

## 1. 계층별 파일 상단 헤더 템플릿 (File Header Banner)

모든 `.js` 및 `.vue` 파일의 최상단(1행 또는 `<script setup>` 직후)에 작성합니다.

### ① API 통신 모듈 (`src/api/*Api.js`)
```javascript
/**
 * ============================================================================
 * @file        파일명 (예: accountYearMonthApi.js)
 * @layer       API Client Layer (Spring의 FeignClient / RestTemplate 역할)
 * @role        역할 한 줄 요약
 * @spring      연동되는 백엔드 Controller 및 Entity 명시
 *              - Controller : AccountYearMonthController (/api/v1/account-year-months)
 *              - Entity/DTO : AccountYearMonth, AccountYearMonthRequest/Response
 * ============================================================================
 */
```

### ② 비즈니스 로직 & 상태 모듈 (`src/composables/use*.js`)
```javascript
/**
 * ============================================================================
 * @file        파일명 (예: useBudget.js)
 * @layer       Service / State Layer (Spring의 @Service + @Transactional 역할)
 * @role        화면의 반응형 데이터(ref), 자동 합산식(computed), API 호출 액션 관리
 * @flow        [Component View] <---> [useXXX (Composable)] <---> [XXXApi] <---> [Spring Server]
 * ============================================================================
 */
```

### ③ 화면 컴포넌트 (`src/components/**/*.vue`)
```javascript
/**
 * ============================================================================
 * @file        파일명 (예: BudgetTable.vue)
 * @layer       Presentation Layer (View / UI Component)
 * @role        사용자에게 표출되는 화면 영역 및 입력 이벤트 바인딩
 * @parent      상위 호출 컴포넌트 (예: BudgetPlannerView.vue)
 * @children    하위 포함 컴포넌트 (예: NumberInput.vue)
 * ============================================================================
 */
```

## 2. 스크립트 내부 구역 구분선 템플릿 (Section Dividers)

파일 내부 코드가 섞이지 않도록 반드시 아래 **5대 표준 구역(Section)** 순서대로 배치하고 구분선을 넣습니다.

```javascript
// ============================================================================
// [SECTION 1] Props & Emits (부모 컴포넌트로부터 받는 데이터와 올려보내는 이벤트)
// - Props : Java 메소드의 입력 파라미터(Parameter)와 동일 (읽기 전용)
// - Emits : 부모 컴포넌트에게 알리는 콜백 이벤트(Callback Event)
// ============================================================================

// ============================================================================
// [SECTION 2] Reactive State (반응형 상태 변수 - ref)
// - ref(초기값)으로 선언된 변수는 값이 변경되면 화면(HTML)이 자동으로 다시 그려집니다.
// - 스크립트(JS) 내부에서는 반드시 `.value`를 붙여 읽거나 수정합니다. (템플릿에서는 생략)
// ============================================================================

// ============================================================================
// [SECTION 3] Computed Properties (파생 계산 속성 - computed)
// - Java의 Getter 계산 메소드나 DB의 View/SUM() 쿼리와 동일합니다.
// - 내부에서 참조하는 ref 변수가 바뀔 때마다 자동으로 재계산되며 캐싱됩니다.
// ============================================================================

// ============================================================================
// [SECTION 4] Watchers & Lifecycle (상태 감시자 및 생명주기 훅)
// - watch     : 특정 변수가 바뀔 때 부수 효과(API 재조회, 로컬스토리지 저장) 실행
// - onMounted : 화면이 브라우저에 처음 그려진 직후 1회 실행 (Spring의 @PostConstruct)
// ============================================================================

// ============================================================================
// [SECTION 5] Business Actions & Event Handlers (비즈니스 액션 및 이벤트 함수)
// - 버튼 클릭(@click), 폼 제출(@submit) 시 실행되는 실제 동작 함수들입니다.
// ============================================================================
```

## 3. 함수 및 API 메소드 JSDoc 템플릿

```javascript
/**
 * [기능 요약 제목]
 * @description 언제 호출되며 내부적으로 어떤 처리를 수행하는지 설명합니다.
 * @http        GET | POST | PUT | DELETE /api/v1/... (API 함수인 경우)
 * @param       {타입} 파라미터명 - 설명
 * @returns     {타입} 반환값 설명
 */
```

## 4. Vue `<template>` 마크업 영역 주석 템플릿

HTML 코드가 길어질 때 어디를 고쳐야 할지 바로 찾을 수 있도록 대단위 블록마다 영역 번호를 붙입니다.

```html
<!-- ====================================================================== -->
<!-- [UI 영역 1] 영역 이름 (예: 상단 연도 선택 및 저장 컨트롤 바)                -->
<!-- - 바인딩 상태 : year, dirtyCount, saving                                -->
<!-- - 발생 이벤트 : @change="changeYear", @click="save"                     -->
<!-- ====================================================================== -->
```
